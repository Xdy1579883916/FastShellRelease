# FastShell

FastShell 是面向开发者和服务器维护人员的 Windows SSH 客户端，集终端、远程文件管理和服务器监控于一体。

## 下载

前往[下载页面](/../../releases)获取 Windows x64 安装包。支持 Windows 10 及以上系统。

安装要求和首次连接步骤见[使用说明](guide.md)。本仓库提供安装包和使用文档，源码尚未开源。

## 功能

| 功能 | 说明 |
| --- | --- |
| SSH 终端 | 多标签、密码与私钥认证、单级跳板机、查找、复制粘贴 |
| 连接管理 | 搜索、分组、批量管理、加密导出、JSON 导入、FinalShell 密码连接导入 |
| 远程文件 | SFTP 目录浏览、搜索与排序、文件和目录传输、复制粘贴、权限设置 |
| 远程编辑 | 多文件标签、语法高亮、查找替换、保存到服务器、图片预览 |
| 服务器监控 | Linux CPU、内存、进程、网络速率与磁盘容量 |
| 服务器工具 | IP 注册信息、路由追踪、进程管理、网络连接与传输测速 |
| 目录与命令 | 历史目录、目录收藏、Bash/Zsh 命令历史、快捷命令 |
| 个性化 | 明亮与黑暗主题、自定义配色、字体、壁纸、分栏布局 |
| App 锁定 | 主密码保护、加密保存凭据、主动锁定 |
