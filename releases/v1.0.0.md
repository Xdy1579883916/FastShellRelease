# FastShell v1.0.0

FastShell 集 SSH 终端、远程文件管理与服务器监控于一体，面向开发者和服务器维护人员。

## 终端与连接

- 多标签 SSH 终端，支持密码、私钥认证和单级跳板机。
- 连接搜索、分组与批量管理，支持加密导出、JSON 导入和 FinalShell 密码连接导入。
- 多行命令输入、Bash/Zsh 命令历史与快捷命令，支持历史目录搜索、收藏和终端跳转。
- App 主密码与锁定功能，凭据加密保存。

## 远程文件与编辑

- SFTP 文件管理，支持目录树、分页、排序、搜索和跟随终端切换目录。
- 文件与目录上传下载、同服务器复制粘贴、批量删除、重命名、创建文件及权限设置。
- 压缩传输、进度显示与取消操作，下载完成后可打开文件或所在目录。
- 多文件编辑标签、语法高亮、查找替换、保存到服务器和图片预览。
- 下载默认保存到安装目录中的 `data` 文件夹，可在设置中更改；目录不可用时提示重新选择。

## 监控与外观

- Linux CPU、内存、进程、网络速率、磁盘容量与 SSH 响应时间监控。
- IP 注册信息、路由追踪、进程管理、网络连接查看和 SSH/SFTP 测速。
- 多套明暗配色，包括吉卜力系列配色；支持字体、壁纸和分栏布局调整。

## 下载与安装

Windows x64 安装包及校验文件：

- `FastShell-v1.0.0-windows-amd64-installer.exe`
- `FastShell-v1.0.0-windows-amd64-installer.exe.sha256`

支持 Windows 10 及以上系统。安装程序支持选择安装目录、创建快捷方式和卸载；缺少 Microsoft Edge WebView2 Runtime 时自动联网安装。安装包尚未进行数字签名。

## 升级

升级前保存编辑内容、结束传输并退出 FastShell，备份数据后运行新安装程序。连接和设置会保留；已设置的下载目录继续使用，未设置时使用安装目录中的 `data` 文件夹。更改安装目录时，原目录中的下载文件不会自动迁移。

详见[使用说明](../guide.md)和[备份与升级](../backup.md)。
