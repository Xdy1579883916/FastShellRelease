# FastShell v1.0.1

完善目录大小统计与文件属性展示，修正弹窗提示的层级。

## 新增

- 目录大小统计实时显示已统计大小、文件数和文件夹数，支持停止和重新统计。

## 改进

- 并发读取子目录，减少目录统计的等待时间。
- 属性窗口精简重复的名称和路径信息，完整路径以单行显示，悬停可查看全部内容。

## 修复

- 关闭属性窗口时取消后台统计；统计超过 2 分钟自动停止，明确标注结果不完整。
- 移除随扫描路径变化的展示行，避免属性窗口高度不断跳动。
- 修正弹窗关闭按钮的 Tooltip 层级，使提示跟随所在弹窗。

## 下载与升级

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
