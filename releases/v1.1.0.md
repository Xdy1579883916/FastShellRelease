# FastShell v1.1.0

增加常用连接排序、分组导入和压缩日志查看，优化文件编辑与主题设置体验。

## 新增

- 快速连接增加“最近”，只显示成功连接过的服务器。连接次数越多越靠前，次数相同时最近使用的优先；全部连接和各分组也采用这个排序。
- FinalShell 导入支持选择备份目录，自动读取子目录中的 SSH 密码连接并保留分组。
- 连接管理器增加“按 IP 去重”，可逐条或批量删除重复连接，被用作跳板机的连接会保留。
- 登录记忆增加“永久”选项，主动锁定仍会清除登录记忆。
- 支持直接查看 `.log.gz` 压缩日志，自动解压并以只读方式打开。
- “设置 → 文件查看”可调整可打开的文件大小，默认 4 MB，支持 1–256 MB；压缩日志按解压后的内容大小计算。

## 改进

- 文件读取显示进度，底部显示文件大小；压缩日志同时显示压缩前后大小。
- 文件属性支持复制文件名和完整路径，连接分组显示连接数量。
- 主题分类与配色卡片更紧凑，当前方案移到列表标题旁，窄窗口自动调整列数。
- 易混淆 Unicode 字符高亮默认关闭，可在编辑器设置中重新开启；保留不可见字符提醒。

## 修复

- 修复 Unicode 提示中的禁用链接点击后未立即生效的问题。
- 修复图片全屏、弹窗内提示、消息和通知的遮挡问题，反复打开弹窗时层级保持稳定。

## 下载与升级

常用连接记录从本版本开始累计，保存在本机，重启后保留。

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
