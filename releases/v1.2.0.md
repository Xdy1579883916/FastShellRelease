# FastShell v1.2.0

新增应用内软件更新，改善远程文件读取、快速连接排序与窗口交互。

## 新增

- 设置中增加“软件更新”，可检查新版本、下载更新并在校验完成后重启安装。
- 默认在启动后检查一次更新，也可选择退出时安装已下载的更新；离线或检查失败不会影响正常使用。
- 应用内更新会检查会话、传输和未保存编辑内容，退出后备份数据；更新失败时可查看原因与备份位置。

## 改进

- 远程文件采用并发预读，提高较大文件的读取效率；文件查看默认上限提高到 20 MB，保留已有设置。
- 快速连接的全部连接与各分组按最近成功连接时间排序，分组名称显示连接数量，移除单独的“最近”入口。
- 默认界面配色改为青绿，界面字体默认使用微软雅黑；保留已有外观设置。
- 更新安装保留已有快捷方式偏好。

## 修复

- 修复窗口边缘缩放与滚动条、文件框选的交互冲突。
- 修复编辑器链接提示复制内容不正确的问题，支持复制实际网址。
- 修复设置页面的区块间距问题。

## 下载与升级

旧版本需下载安装包升级至本版本，之后可使用应用内软件更新。自动更新适用于 Windows x64 安装版。

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
