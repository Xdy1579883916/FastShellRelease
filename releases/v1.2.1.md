# FastShell v1.2.1

修复软件更新页面的版本说明展示，改善阅读体验。

## 修复

- 版本说明按 Markdown 格式展示，正确显示标题、列表、加粗、链接、代码块和表格。
- 版本说明随设置页面统一滚动，长文本自动换行，图片和表格适应内容区域宽度。

## 改进

- 开发构建可在软件更新页面获取、刷新线上发布信息并预览版本说明，下载和安装更新保持禁用。
- 版本说明中的网页链接通过系统浏览器打开。

## 下载与升级

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件，也可通过应用内“软件更新”升级。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
