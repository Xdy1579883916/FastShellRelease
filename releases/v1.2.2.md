# FastShell v1.2.2

新增更新下载的代理与加速配置，优化软件更新页面和通知体验。

## 新增

- 软件更新中新增网络设置，支持 HTTP、HTTPS、SOCKS5 代理及自定义 GitHub 下载加速地址，可根据网络情况选择直接连接或代理。
- 发现新版本、安装包下载完成及更新成功时，通过右上角通知提示；点击“查看更新”可进入软件更新页面。

## 改进

- 重新整理软件更新页面，将版本概览、自动更新选项和网络设置分区展示，网络设置默认收起。
- 更新通知可关闭，不再占用主界面空间；下载进度变化不会反复弹出通知。
- 网络连接失败时，显示失败阶段、目标域名和具体原因，方便调整网络设置。

## 修复

- 修复启用下载加速后，仍因直连 GitHub 获取校验文件超时而无法下载的问题；支持使用官方版本信息中的 SHA256 校验安装包。
- 补全发现新版本时的通知，修复只有下载完成后才显示更新提示的问题。

## 下载与升级

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件，也可通过应用内“软件更新”升级。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
