# FastShell v1.2.3

减少更新通知打扰，并支持跳过暂不需要的新版本。

## 新增

- 更新通知和软件更新页面增加“跳过此版本”。跳过后不再提醒或自动下载该版本，正在下载时会取消，已下载的该版本也不会在退出时安装；重启软件后仍然有效。
- 软件更新页面支持“恢复此版本更新”，恢复后可手动下载或安装。后续发布其他新版本时，仍会正常提醒。

## 修复

- 修复安装更新后，每次关闭并重新打开软件都会显示更新成功通知的问题。当前已是最新版或安装成功时不再主动弹窗，更新记录仍可在软件更新页面查看。

## 下载与升级

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件，也可通过应用内“软件更新”升级。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
