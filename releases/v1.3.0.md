# FastShell v1.3.0

增强远程文件管理、服务器监控与排障工具，并优化浅色界面的信息层次。

## 新增

- 服务器工具按服务器概览、资源监控、排障工作台、网络诊断四个分区组织，支持系统环境与常用命令检测。
- 资源监控增加磁盘读写与分组采样，支持分别设置刷新频率；连接期间持续记录资源趋势。
- 排障工作台增加进程详情、关联连接与系统服务查看，支持服务操作、服务日志查询和文件日志实时跟踪。
- 网络诊断增加持续路由探测、远端探测与报告导出，便于观察连接变化。
- 文件管理增加所有者修改、递归文件与内容搜索、原地打包和解压，以及配置差异预览、备份发布与恢复。

## 改进

- 优化文件管理布局与当前目录定位，完善图片预览和 SVG 源码切换。
- 浅色服务器工具使用清晰的卡片边界、正文背景和详情标题栏，便于区分导航与内容。
- 切换工具页面时先结束上一项任务，再加载新页面；停止任务后显示清理进度。

## 修复

- 修复工具切页时旧请求与新任务抢占、迟到结果更新当前页面的问题。
- 修复首页滚动区域与窗口缩放边缘冲突的问题。

## 下载与升级

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件，也可通过应用内“软件更新”升级。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
