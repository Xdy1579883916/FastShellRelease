# FastShell v1.4.0

新增无 App 密码模式和忘记密码入口，并修复登录提示间距与首页壁纸在明暗主题下的显示。

## 新增

- 首次启动可选择“不设置密码，直接进入”，以后打开应用直接进入工作区。
- “设置 → 安全”支持在密码保护与无密码模式之间切换，保存的服务器凭据会保留；已有密码切换为无密码时需验证当前密码。
- 登录页增加“忘记密码？”入口，输入“清空保险库”确认后删除保存的凭据和登录记忆，保留连接配置与分组，再重新选择使用模式。
- 软件更新内置 5 条 GitHub 下载加速线路，支持从下拉列表选择，也保留官方直连与自定义地址。

## 改进与修复

- 无密码模式下隐藏主动锁定入口，导出连接使用自定义密码。
- 调整登录错误提示、清空确认警告和操作按钮之间的间距，小窗口可滚动查看完整内容。
- 修复明亮主题首页的壁纸被遮盖的问题，首页壁纸底色、文字与控件一起跟随主题，保留所选图片和透明度。

## 数据与升级

原有密码保护模式保持兼容，无需重新设置。无密码模式仍加密保存凭据，由当前 Windows 用户保护；换电脑或 Windows 用户前，请使用自定义密码导出连接，或先切换为密码保护后备份数据库。忘记密码重置无法恢复原有凭据。

使用无密码模式后，如需回退旧版本，请先用本版本切换为密码保护；旧版本无法读取无密码模式的数据格式。备份与迁移步骤见[备份与升级](../backup.md)。

## 下载与升级

从[下载页面](/../../releases)获取 Windows x64 安装包和 SHA256 校验文件，也可通过应用内“软件更新”升级。操作步骤见[使用说明](../guide.md)。
