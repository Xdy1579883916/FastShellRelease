# FastShell v1.4.2

修复文件拖入过程中的窗口手势冲突，以及部分服务器连接后的 nvm 初始化报错。

## 修复

- 从其他程序拖入文件、经过标题栏时，不再将外部拖拽误判为窗口移动或缩放。
- 清理窗口失焦及文件拖入时遗留的鼠标手势状态，保留正常的标题栏移动和边缘缩放。
- 修复 Windows 下拖出文件列表或取消拖拽后，上传提示可能残留的问题。
- 修复部分服务器终端登录时出现 `nvm_find_up: command not found`、`nvm: command not found` 的问题，保留终端目录跟随。

## 下载与升级

从[下载页面](/../../releases)获取安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
