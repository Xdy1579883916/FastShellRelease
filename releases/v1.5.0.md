# FastShell v1.5.0

支持多选文件与双向压缩传输，并将传输进度调整为右上角浮层。

## 新增

- 上传文件支持 Ctrl / Shift 多选，多个文件和目录可打包上传，完成后自动解压。
- “设置 → 文件传输”提供独立的“压缩上传”和“压缩下载”开关，默认开启，保存后自动应用，无需每次选择传输方式。服务器不支持时自动直接传输。

## 改进

- 传输记录入口移至主界面右上角，进度以无遮罩浮层展示。点击外部或按 Esc 收起，后台传输继续运行。
- 收紧传输进度浮层尺寸，优化长路径、错误信息和列表滚动。
- 精简文件传输设置说明，调整上传、下载分区与开关排版。

## 下载与升级

- 升级后压缩上传和压缩下载默认开启，可在“设置 → 文件传输”分别关闭。
- 修改压缩下载设置仅影响之后准备的下载任务。

从[下载页面](/../../releases)获取安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
