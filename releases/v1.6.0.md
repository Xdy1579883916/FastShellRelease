# FastShell v1.6.0

重新连接服务器时，自动回到上次的文件目录和 Shell 工作目录。

## 新增

- 每个已保存连接分别记住文件面板目录与 Shell 当前目录，关闭连接、重新连接或重启应用后自动恢复，无需额外设置。
- 目录记录加密保存在本机，随数据库备份保留。

## 改进

- 恢复时若原目录已删除、变成文件或无法访问，自动使用默认目录，不弹出目录恢复错误。
- 文件面板与 Shell 分别恢复各自的位置；之后在 Shell 中切换目录，文件面板继续跟随。

## 下载与升级

目录记忆从升级后开始积累。Shell 目录记忆需要服务器支持 Linux `/proc` 目录跟踪；重新连接会启动新的 Shell，不恢复旧进程或终端输出。

从[下载页面](/../../releases)获取安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
