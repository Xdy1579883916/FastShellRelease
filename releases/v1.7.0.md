# FastShell v1.7.0

目录恢复由你选择，设置分类更集中、布局更紧凑。

## 新增

- “设置 → 连接”新增“恢复终端工作目录”和“恢复文件面板目录”两个独立选项，默认关闭，保存后从下次连接生效。
- 两个目录按连接分别记忆在当前设备，目录记录加密保存，不随连接导出，不影响其他设备。

## 改进

- 设置整合为连接、外观、文件、监控、安全和软件更新六类。主题、字体、壁纸归入外观，查看、上传、下载归入文件。
- 外观使用紧凑的页内分组，统一缩小设置页留白；切换分类时回到内容顶部。
- 文件查看与传输偏好可一次保存，部分保存失败时明确显示结果，并支持重试。
- 文件面板不再自动跟随终端的目录变化，保留主动“终端跳转到此目录”操作。

## 下载与升级

升级后两项目录恢复默认关闭，需要时可在“设置 → 连接”开启。原有目录记录继续保留；文件面板恢复其最后成功打开的位置，原目录不可用时使用默认目录。

终端目录记忆依赖服务器支持 Linux `/proc` 跟踪。自动恢复会执行目录切换命令，是否进入命令历史取决于服务器的 Shell 设置。

从[下载页面](/../../releases)获取安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
