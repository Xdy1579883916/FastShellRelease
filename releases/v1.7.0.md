# FastShell v1.7.0

支持分别设置终端和文件面板的目录恢复，并优化设置页面。

## 新增

- “设置 → 连接”新增“恢复终端工作目录”和“恢复文件面板目录”两个独立开关，可分别选择是否在连接时回到上次的目录。

## 改进

- 设置页面整合为连接、外观、文件、监控、安全和软件更新六类，减少分类与页面留白。
- 主题、字体和壁纸集中在“外观”中；文件查看、上传和下载选项集中在“文件”中，文件设置可统一保存。
- 文件面板保持独立浏览位置，在终端中切换目录时不再自动跳转。仍可使用“终端跳转到此目录”让终端进入文件面板当前目录。

## 下载与升级

升级后，终端和文件面板的目录恢复均默认关闭。如需继续使用，请在“设置 → 连接”中分别开启，下次连接生效。已有目录记录保留在当前设备，原目录不可用时使用默认目录。

从[下载页面](/../../releases)获取安装包和 SHA256 校验文件。安装步骤见[使用说明](../guide.md)，数据备份与升级步骤见[备份与升级](../backup.md)。
